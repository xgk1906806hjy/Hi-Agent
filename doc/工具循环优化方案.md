# 工具循环优化方案

对照 OpenCode / Codex / Claude Code，优化 Hi-agent 的 agent 循环护栏与收尾体验。  
**本阶段只改循环与提示，不推进 Day6+ 功能。**

## 1. 现状

| 能力 | 状态 |
|------|------|
| 可配轮次上限 | ✅ `GEEKAGENT_MAX_TOOL_TURNS` |
| 强制收尾 + 总结 system | ✅ |
| 滑动窗口重复熔断 | ✅ |
| `/status` + Ctrl+C | ✅ |
| 单次回复字符预算 | ✅ `GEEKAGENT_MAX_REPLY_CHARS` |
| 后期只读工具收缩 | ✅ `GEEKAGENT_SHRINK_TOOLS_AFTER` |
| Day8 权限联动 | ❌ 待 Day8 |
| 真实 USD 计费预算 | ❌ 不做（无定价表；用字符代理） |

## 2. 分阶段

### P0–P2（均已落地）

见上文表格。预算以 Unicode 字符计（模型正文 + 工具返回），默认 12 万，`0` 关闭。  
收缩默认从约 `3/4 * maxTurns` 轮起只暴露 `get_current_time/ls/glob/read`，`0` 关闭。

### 后续（非本方案）

- Day6 多会话、Day8 权限/undo  
- 若有 API usage 字段，可再叠 token 面板（Day7）

## 3. 验收

1. 轮次/重复/预算触顶均强制收尾且会话可继续。  
2. `GEEKAGENT_SHRINK_TOOLS_AFTER=1` 时第 2 轮起进度提示「工具集收缩」，且不可再调 `write`。  
3. `GEEKAGENT_MAX_REPLY_CHARS=500` 时易触发预算收尾。  
4. `/status` 显示预算与收缩。  
5. `go test ./internal/chat ./internal/tools` 与 `go build ./cmd/hi-agent` 通过。

## 4. 非目标

- 无限循环、完整 permission 模型、按美元精确计费
