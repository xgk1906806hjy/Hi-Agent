# web — 改动记录

## 2026-10-27 — Day 16 Web 模式（HTTP + SSE）

- 新增 `internal/webui`：注册 `ui.KindWeb`，复用 `internal/gui` 的 `Adapter` / `Snapshot` / 事件协议；实现 HTTP 服务、SSE 广播、提交/停止/对话框接口与内嵌页面。
- 页面支持对话、状态、项目/会话切换、斜杠命令、确认/选择框；默认监听 `127.0.0.1:8787`，可用 `GEEKAGENT_WEB_ADDR` 修改。
- `cmd/hi-agent` 在 Web 模式使用 `config.LoadE`，缺失模型配置不退出；`DesktopRunner` 主线程运行 HTTP 服务。
- 影响范围：`internal/webui/*`、`cmd/hi-agent/main.go`、`internal/ui`（Kind 状态说明）、`docs/web/*`、`README.md`、`openspec/changes/day16-plugins/`。
