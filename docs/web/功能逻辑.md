# web — 功能逻辑

## 1. 职责

浏览器界面（`ui.KindWeb`）：用 HTTP + Server-Sent Events 把 REPL 暴露到本机浏览器。复用 `internal/gui` 的 `Adapter`、`Snapshot` 与事件载荷，因此 Go 侧不需要为 Web 写第二套对话循环。

代码：`internal/webui/`。

| 文件 | 说明 |
|------|------|
| `webui.go` | `ui.Register(KindWeb)`；创建 `gui.Adapter`，把 `Run` / `Quit` 接到 HTTP 服务 |
| `server.go` | HTTP 路由、SSE 广播、提交/停止/对话框接口 |
| `static/index.html` | 内嵌轻量页面：消息流、状态、项目/会话、斜杠命令、确认/选择框 |

## 2. 启动

1. `GEEKAGENT_UI=web hi-agent`（或 `HI_AGENT_UI=web`）。
2. `config.LoadE()`：缺模型配置时进入页面后用 `/model` 补，不直接退出。
3. `ui.Create(KindWeb)` 返回一个实现 `ui.UI + ui.DesktopRunner + ui.Canceler` 的 `gui.Adapter`。
4. `main` 把 REPL 放进 goroutine，主线程执行 `Adapter.Run()`；`Server.Run` 监听 `GEEKAGENT_WEB_ADDR`（默认 `127.0.0.1:8787`），向 stderr 打印地址。
5. 浏览器打开页面后加载快照，再建立 `/api/events` SSE；`Adapter.Attach` 冲刷启动前排队的 banner/status 事件。
6. `/exit` 或空闲 Ctrl+C 走正常 `exit()`：插件/MCP 关闭、会话保存、`Adapter.Close()` → `Server.Shutdown()`，`Run()` 返回。

## 3. HTTP 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 内嵌页面 |
| GET | `/api/events` | SSE；事件名与 `internal/gui/protocol.go` 一致（`chat:*`、`turn:*`、`status`、`nav`、`dialog:*`、`input:prompt`） |
| GET | `/api/snapshot` | `gui.Snapshot`：`{status,nav,prompt,slash}` |
| POST | `/api/submit` | `{"text":"..."}`，送入 REPL 主循环 |
| POST | `/api/stop` | 中断当前回复 |
| POST | `/api/answer` | `{"id":"d1","value":1}`，回答确认/选择框 |

SSE 格式：

```text
event: chat:delta
data: {"text":"你"}

```

服务端每 15 秒发送 `: ping` 注释保活；慢客户端队列满时丢弃事件，不阻塞 REPL。

## 4. 页面行为

- 顶部显示模型、供应商、会话与工作目录；生成中禁用发送、显示“停止”。
- 侧栏显示 `nav.projects`：点项目提交 `/project <path>`，点会话提交 `/open <id>` 或 `/open <id> <path>`。
- 斜杠命令来自快照 `slash`，点击后填入输入框。
- `chat:user` / `chat:delta` 渲染对话；`chat:progress` / `chat:info` / `chat:notice` / `chat:error` 渲染过程与提示；`chat:reset` 按 `turns` 重绘。
- `dialog:confirm` 使用浏览器确认框，`dialog:select` 使用带编号的输入框；回答通过 `/api/answer` 回传。

## 5. 环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `GEEKAGENT_UI` / `HI_AGENT_UI` | — | 设为 `web` 启用 |
| `GEEKAGENT_WEB_ADDR` | `127.0.0.1:8787` | 监听地址；默认只绑回环 |

## 6. 边界

- 仅面向本机开发/演示：没有鉴权、HTTPS、多用户隔离；不要把 `GEEKAGENT_WEB_ADDR` 暴露到公网。
- 页面是内嵌单文件 HTML，不依赖 `internal/gui/frontend/dist` 或 Node 构建；事件协议与 `gui` 保持同构。
- 项目/会话操作复用 REPL 的斜杠命令，不在 Web 层直接读会话文件。
- 一个进程只建议开一个浏览器标签页；多标签会共享同一个 REPL 与输入队列，事件会广播到所有已连接标签。
