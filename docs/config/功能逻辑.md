# config — 功能逻辑

## 1. 职责

从**多层 .env** 与进程环境变量加载 OpenAI 兼容接口配置，经**供应商工厂**解析为 `Endpoint`，并记录启动时的工作目录。  
工具读写、会话落盘均相对进程 cwd，因此可在任意项目路径下启动同一份 `hi-agent` 二进制。

## 2. 代码位置

| 文件 | 说明 |
|------|------|
| `internal/config/config.go` | `Config`、`Load` / `LoadE`（不退出版，供 GUI）、分层 dotenv |
| `internal/config/provider.go` | 供应商注册表、`ResolveEndpoint` 工厂 |
| `internal/config/config_test.go` | 路径链与环境快照还原 |
| `internal/config/provider_test.go` | 工厂解析与注册 |
| `internal/config/persist.go` | `ApplyEndpoint` / `UpsertEnvFile`：运行时写回全局 .env |
| `internal/config/setup_env.go` | `ApplyEnvFile`：解析 .env → 写全局 |
| `internal/config/setup_env_windows.go` | Windows 用户环境变量 |
| `internal/config/setup_env_unix.go` | Unix：`env.sh` + shell rc 挂载 |
| `scripts/setup-env.{ps1,cmd,sh}` | 跨平台一键脚本入口 |

## 3. 数据结构

```go
type Config struct {
    Provider string
    BaseURL  string
    APIKey   string
    Model    string
    WorkDir  string
    EnvFiles []string
}

type Provider struct { ID, Name, DefaultURL, DefaultModel, KeyEnv string }
type Endpoint struct { Provider, BaseURL, APIKey, Model string }
```

## 4. 供应商工厂

| API | 说明 |
|-----|------|
| `RegisterProvider` | 注册/覆盖供应商（扩展中转站） |
| `LookupProvider` / `ListProviders` | 查询 |
| `ResolveEndpoint(id, getenv)` | 解析最终端点 |
| `ResolveEndpointFromEnv` | 读进程环境解析 |
| `ProviderHelp` | `/help` 文案 |

内置 id：`deepseek`（默认）、`openai`、`moonshot`、`qwen`、`zhipu`、`siliconflow`、`openrouter`、`groq`、`ollama`、`custom`。

选择供应商：`GEEKAGENT_PROVIDER` 或 `HI_AGENT_PROVIDER`。未设置时：若 `OPENAI_BASE_URL` 能匹配某默认 URL 则推断，否则有 URL → `custom`，都没有 → `deepseek`。

覆盖优先级（高 → 低）：

- URL：`OPENAI_BASE_URL` / `HI_AGENT_BASE_URL` → 供应商默认  
- Model：`OPENAI_MODEL` / `HI_AGENT_MODEL` → 供应商默认  
- Key：`OPENAI_API_KEY` / `HI_AGENT_API_KEY` / `GEEKAGENT_API_KEY` → 供应商 `KeyEnv`

自定义中转：`GEEKAGENT_PROVIDER=custom` + 自填 `OPENAI_BASE_URL`（及 Key、Model）。

## 5. 环境变量（核心）

| 变量 | 是否必填 | 说明 |
|------|----------|------|
| `OPENAI_API_KEY` 等 | **是**（见工厂回退） | 密钥 |
| `OPENAI_BASE_URL` | custom 必填 | 接口根 |
| `OPENAI_MODEL` | 多数可默认 | 模型名 |
| `GEEKAGENT_PROVIDER` | 否 | 供应商 id |

`GEEKAGENT_*` 与厂商 Key 亦参与「进程环境快照还原」。

## 6. `.env` 加载优先级（高 → 低）

1. **进程环境变量**  
2. **工作目录向上** `.env`  
3. **用户全局** `~/.hi-agent/.env`

## 7. `setup-env`

复制 `.env` → 全局；持久化 `OPENAI_*`、`GEEKAGENT_PROVIDER`、`HI_AGENT_*` 等到用户环境。

## 8. 边界

- 仅 OpenAI 兼容 HTTP；不接专有非兼容 SDK。  
- 不验证 URL / 密钥有效性。  
- 会话仍落在 **cwd** 的 `.geekagent/`。
