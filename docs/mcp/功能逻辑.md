# mcp — 功能逻辑

## 1. 职责

Day 15 的 MCP 客户端（Model Context Protocol，stdio）：读取项目 `.geekagent/mcp.json`，启动并握手外部 MCP server，把其 tools 以 `mcp_<server>_<tool>` 注册到 `internal/tools`，供模型调用；`/mcp` 查看连接状态。

代码：`internal/mcp/`。本包不负责 UI 渲染；REPL 提供 `/mcp`，GUI 通过 `ui.Status.MCP` 展示状态。

## 2. 配置文件

路径：工作区 `.geekagent/mcp.json`（不入库）。

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "."],
      "env": { "EXAMPLE": "1" },
      "cwd": "."
    }
  }
}
```

- 兼容两种顶层键：`mcpServers`（优先）与 `servers`。
- `command` 必填；`args`、`env`、`cwd` 可选。
- `cwd` 相对工作区；缺省为工作区根。
- 配置文件不存在：视为未配置，不报错。
- JSON 损坏：显示配置错误，不注册任何 MCP 工具。

## 3. 连接与工具注册

1. `exec.Command` 启动 stdio server，继承进程环境并叠加 `env`。
2. 发送 `initialize`（protocolVersion `2024-11-05`，clientInfo `hi-agent`），随后发送 `notifications/initialized`。
3. 调 `tools/list`，支持 `nextCursor` 分页；每个工具注册为：
   - 名称：`mcp_<server>_<tool>`；非法字符替换为 `_`，过长名称截断并加哈希，避免超过 OpenAI function 名长度。
   - 描述：`MCP[server] 原描述`。
   - 参数：server 返回的 `inputSchema` 原样传给工具注册表；缺失时用空 object schema。
4. 调 `tools/call`，参数 JSON 原样转发；文本内容拼接返回，图片等非文本内容用占位说明，不把大段 base64 塞进上下文。
5. server 断开、初始化失败或工具列表失败：该 server 记为未连接，不影响其它 server；断开后不自动重连，关闭/重载时移除已注册工具。

## 4. 生命周期与命令

- 启动：REPL 在权限钩子安装后调用 `Manager.Load(workDir)`；加载失败只提示，不阻断对话。
- `/project`：关闭旧 server、移除旧动态工具，按新工作区重新加载。
- `/mcp`：显示配置错误或每个 server 的连接状态与工具数。
- `/mcp reload`：重新读取 `.geekagent/mcp.json` 并连接。
- 退出：`Manager.Close()` 关闭全部子进程并移除动态工具。

## 5. 权限

MCP 工具不会绕过 Day 8：

- 动态工具名默认不在内置策略表中，因此默认 **deny**。
- 用户需在 `.geekagent/GeekAgent.json` 或 `~/.hi-agent/GeekAgent.json` 放行，例如：

```json
{ "permissions": {
    "allow": ["mcp_filesystem_read_file"]
} }
```

或使用通配 `"mcp_filesystem_*"`。权限判断发生在 `tools.Exec`，与普通工具一致。

## 6. 边界

- 只实现 stdio transport；不做 HTTP/SSE、OAuth、resources/prompts/sampling。
- 不做自动重连、后台轮询或工具列表热更新；配置变更用 `/mcp reload`。
- 仅暴露 tools；MCP server 的资源和提示词不注册为工具。
- 启动/握手/列表请求有超时；工具调用有单次超时，避免子进程卡死整个 REPL。
- 进程工作目录为工作区；server 自身的文件权限不因 PathGuard 自动收紧，需用户选择可信 server。

## 7. 依赖

| 方向 | 对象 |
|------|------|
| 外部 | 标准库 `os/exec`、`encoding/json`、`bufio` |
| 内部 | `internal/tools`（动态注册/注销） |
| 调用方 | `cmd/hi-agent`（启动、`/project`、`/mcp`、退出关闭） |
