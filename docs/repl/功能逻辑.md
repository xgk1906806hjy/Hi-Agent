# repl — 功能逻辑

## 1. 职责

进程入口与终端交互层：加载配置与会话、接线确认、斜杠命令（含参数）、驱动 `chat.StreamReply`、退出时保存会话。

代码：`cmd/hi-agent/main.go`（`package main`）。

## 2. 启动流程

1. `config.Load()`（缺 Key 则退出）  
2. `chat.New`  
3. `session.Load()` → 失败则空 `NewData` + 告警  
4. `session.NewManager(chat, data)`（把当前会话 history 灌入 Chat）  
5. `tools.SetConfirm`  
6. Banner：模型 + **当前会话 ID**  

## 3. 斜杠命令

命令按 `strings.Fields` 拆分：`cmd` + `args`（不再要求整行精确等于命令）。

| 命令 | 行为 |
|------|------|
| `/help` | 帮助 |
| `/status` | 当前会话 ID + `Chat.Status()` |
| `/sessions` | 列出会话（`*` 标记当前） |
| `/new [id]` | 新建空会话并切换；省略 id 则 8 位 hex |
| `/open <id>` | 切换到已有会话 |
| `/save` | 全部会话写入 `.geekagent/sessions.json` |
| `/load` | 从磁盘重载（丢弃未保存内存改动） |
| `/reset` | 清空当前 Chat history，并 Sync 到会话 |
| `/compact` | 压缩后 Sync |
| `/exit` | `PrepareExit`（default 有内容则改名）+ 保存 + bye |

## 4. 普通对话

与此前相同：`NotifyContext` + `StreamReply` + 进度行染黄；中断不退出。  
对话结束后 **不自动写盘**（避免每句落盘）；`/save` 或 `/exit` 时保存。

## 5. 退出

- `/exit` 或 stdin EOF：均走 `exitWithSave` → `PrepareExit`。  
- `default` 且有消息：重命名为 8 位 ID 再保存。

## 6. 边界

- 无 TUI（Day7）。  
- `/load` 会覆盖未 `/save` 的改动。
