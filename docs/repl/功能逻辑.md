# repl — 功能逻辑

## 1. 职责

进程入口与终端交互层：加载配置与会话、接线确认、斜杠命令、驱动 `chat.StreamReply`、用量面板刷新、退出时保存会话并恢复终端。

代码：`cmd/hi-agent/main.go`、`model_cmd.go`（`package main`）。  
界面经 `internal/ui` 工厂创建（不再内嵌 UI 实现）。

## 2. 启动流程

若 `os.Args[1] == "setup-env"`：调用 `config.ApplyEnvFile` 后退出（不进入 REPL）。

否则：

0. `applyLaunchDefaults`：构建期 `main.defaultUI`（GUI 版 exe 为 `gui`）在环境未指定界面时生效；首个参数为目录则 `chdir` 过去  
1. `config.Load()`（分层 .env + 校验 Key；得到 `WorkDir`）；GUI 模式改用 `config.LoadE()`，缺配置不退出，窗口内提示 `/model`  
2. `chat.New`  
3. `session.Load()`（相对 **cwd** 的 `.geekagent/sessions.json`）  
4. `session.NewManager`  
5. `ui.Create(ui.ResolveKind(), …)`（默认 tui；可 plain；gui 须桌面版二进制；web 预留）  
6. 用量 hook、确认、Day 8 钩子（`installPermissions`：`permission.Load(workDir)` → `tools.SetPolicy`；`SafePath(workDir)` → `SetPathGuard`；`Redact(·, apiKey)` → `SetRedactor`；钩子读 app 当前字段，`/project` 后 `reloadPolicy`，`/model` 改 Key 自动生效；配置损坏提示并回退默认）、空闲 Ctrl+C  
7. 若为 `DesktopRunner`（GUI）：REPL 进 goroutine，主线程 `Run()`；否则直接进循环  
8. Banner：打印工作目录、模型、会话；GUI 仅短欢迎；若有则列出已加载 `.env`  

桌面版通过 `desktop_on.go`（`desktop` 标签）导入 `internal/gui` 完成工厂注册；REPL 本身不依赖 GUI 包，侧栏数据由 `workspace` + `ui.Nav` 组装。  

## 3. 斜杠命令

| 命令 | 行为 |
|------|------|
| `/` | 命令菜单（↑/↓ 选择） |
| `/model` | 模型配置菜单（↑/↓）→ 进入对应配置页；可持久化到全局 `.env` |
| `/help` | 帮助（含全局安装与 cwd 说明） |
| `/pwd` | 显示工作目录与会话路径 |
| `/status` | 工作目录 + 供应商/模型 + `Chat.Status()` |
| `/project <目录>` | 保存当前会话后切换工作目录并加载该项目会话 |
| `/sessions` `/new` `/save` `/load` | 多会话 |
| `/open <id> [目录]` | 打开会话；带目录（id 后整段，可含空格）时先 `switchProject`，失败即止 |
| `/rename <新>` / `/rename <旧> <新>` | 重命名会话并保存 |
| `/delete <id>` | `ui.Confirm` 后删除并保存；删当前会话切到最近更新的另一个 |
| `/undo` | `tools.UndoLast`：撤销最近一次 write/patch（单步） |
| `/permissions` | 重新读取并显示权限规则（配置文件 + 内置默认） |
| `/reset` `/compact` `/exit` | 同前 |

## 4. 工作目录语义

- `ls` / `glob` / `read` / `write` / `patch` / `run_shell` 相对进程 cwd。  
- 在仓库外任意项目执行 `hi-agent`，即操作该项目文件。  
- 不自动 `chdir`；用户通过「先 cd 再启动」选择项目。  

## 5. 普通对话

1. `UserEcho` → `BeginReply` → `StreamReply`（进度行走 `Progress`，正文走 `Model`）  
2. 默认折叠：工具进度并入摘要行；正文中的思考标签拆入过程块  
3. `EndReply`；中断提示不退出  
4. 对话不自动写盘（`/save` 或退出时保存）  
5. 输入行：`/` 提示命令、Tab 补全；PgUp/PgDn 滚动消息（生成中不可滚）  

## 6. 中断与退出

| 场景 | 行为 |
|------|------|
| 回复中 Ctrl+C | `NotifyContext` 取消 → `ErrInterrupted` |
| 回复中点 GUI「停止」 | `ui.Canceler` 注入的 cancel → `ErrInterrupted` |
| 空闲 Ctrl+C | 走 `exit()`：保存会话、`ui.Close()`、打印 bye、`os.Exit(0)` |
| `/exit` / EOF | 同上（无 `os.Exit`） |

## 7. 环境变量（本层）

| 变量 | 默认 | 说明 |
|------|------|------|
| `GEEKAGENT_UI` / `HI_AGENT_UI` | `tui` | `tui` / `plain` / `gui`（`web` 预留） |
| `GEEKAGENT_TUI` | 开启 | `0` 兼容为 plain |
| `GEEKAGENT_FOLD` | 开启 | `0` 展开工具/思考全文 |
| `GEEKAGENT_STREAM_USAGE` | 开启 | `0` 关闭 `stream_options`（兼容部分网关） |
| `GEEKAGENT_CONTEXT_WINDOW` | `128000` | 面板上下文窗口上限 |

## 8. 边界

- `historySnapshot`（GUI 重绘）按 `ToolCallID` 把工具结果配回调用，截前 300 字。  
- 主循环提示固定为 `ui.MainPrompt`；其它提示表示命令在索取参数（GUI 据此锁侧栏）。  
- `/load` 覆盖未保存改动。  
- UI 创建失败或 TUI 启动失败自动回退 plain。
