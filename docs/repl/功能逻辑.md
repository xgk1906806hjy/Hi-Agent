# repl — 功能逻辑

## 1. 职责

进程入口与终端交互层：加载配置与会话、接线确认、斜杠命令、驱动 `chat.StreamReply`、用量面板刷新、退出时保存会话并恢复终端。

代码：`cmd/hi-agent/main.go`、`ui.go`（`package main`）。

## 2. 启动流程

1. `config.Load()`（缺 Key 则退出）  
2. `chat.New`  
3. `session.Load()` → 失败则空 `NewData` + 告警  
4. `session.NewManager(chat, data)`  
5. 选择 UI：TTY 且未设 `GEEKAGENT_TUI=0` → `tui.TUI`，否则 `plainUI`  
6. `chat.SetUsageHook(ui.Refresh)`；`tools.SetConfirm(ui.Confirm)`  
7. 空闲 Ctrl+C 监听（busy 时忽略，交给回复中的 NotifyContext）  
8. Banner  

## 3. UI 抽象

| 方法 | 含义 |
|------|------|
| `Info` / `Notice` / `Error` | 系统 / 提示 / 错误 |
| `UserEcho` | TUI 回显用户输入；纯文本模式空操作 |
| `Progress` / `Model` | 工具进度 / 模型正文 |
| `BeginReply` / `EndReply` | 回复起止（面板「生成中」） |
| `Refresh` | 用量更新后重绘面板 |
| `ReadLine` / `Confirm` | 读行与写前确认 |
| `Close` | 退出 TUI / 无操作 |

## 4. 斜杠命令

命令按 `strings.Fields` 拆分：`cmd` + `args`。

| 命令 | 行为 |
|------|------|
| `/help` | 帮助 |
| `/status` | 当前会话 + `Chat.Status()`（含 tokens） |
| `/sessions` | 列出会话（`*` 标记当前） |
| `/new [id]` | 新建空会话并切换 |
| `/open <id>` | 切换到已有会话 |
| `/save` / `/load` | 落盘 / 重载 |
| `/reset` | 清空当前会话记忆并 Sync |
| `/compact` | 压缩后 Sync |
| `/exit` | `PrepareExit` + `ui.Close` + bye |

## 5. 普通对话

1. `UserEcho` → `BeginReply` → `StreamReply`（进度行走 `Progress`，正文走 `Model`）  
2. `EndReply`；中断提示不退出  
3. 对话不自动写盘（`/save` 或退出时保存）

## 6. 中断与退出

| 场景 | 行为 |
|------|------|
| 回复中 Ctrl+C | `NotifyContext` 取消 → `ErrInterrupted` |
| 空闲 Ctrl+C | 走 `exit()`：保存会话、`ui.Close()`、打印 bye、`os.Exit(0)` |
| `/exit` / EOF | 同上（无 `os.Exit`） |

## 7. 环境变量（本层）

| 变量 | 默认 | 说明 |
|------|------|------|
| `GEEKAGENT_TUI` | 开启 | `0` 强制纯文本 |
| `GEEKAGENT_STREAM_USAGE` | 开启 | `0` 关闭 `stream_options`（兼容部分网关） |
| `GEEKAGENT_CONTEXT_WINDOW` | `128000` | 面板上下文窗口上限 |

## 8. 边界

- 无权限 / undo（Day8）。  
- `/load` 覆盖未保存改动。  
- TUI 启动失败自动回退纯文本。
