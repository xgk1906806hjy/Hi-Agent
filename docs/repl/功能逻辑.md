# repl — 功能逻辑

## 1. 职责

进程入口与终端交互层：加载配置与会话、接线确认、斜杠命令、驱动 `chat.StreamReply`、用量面板刷新、退出时保存会话并恢复终端。

代码：`cmd/hi-agent/main.go`、`model_cmd.go`（`package main`）。  
界面经 `internal/ui` 工厂创建（不再内嵌 UI 实现）。

## 2. 启动流程

若 `os.Args[1] == "setup-env"`：调用 `config.ApplyEnvFile` 后退出（不进入 REPL）。

否则：

0. `applyLaunchDefaults`：构建期 `main.defaultUI`（GUI 版 exe 为 `gui`）在环境未指定界面时生效；首个参数为目录则 `chdir` 过去  
1. `config.Load()`（分层 .env + 校验 Key；得到 `WorkDir`）；GUI / Web 模式改用 `config.LoadE()`，缺配置不退出，界面内提示 `/model`
2. `chat.New`，并注入 `chat.SetRecall(memory.RecallNote)`（主动记忆随 cwd 读取当前项目）
3. `session.Load()`（相对 **cwd** 的 `.geekagent/sessions.json`）
4. `session.NewManager`
5. `ui.Create(ui.ResolveKind(), …)`（默认 tui；可 plain；gui 须桌面版二进制；web 走 `internal/webui`）
6. 扫描 `skills/*/SKILL.md`（`reloadSkills`）：恢复/校验当前进程已加载技能，并注入 `chat.SetSkills`
7. 用量 hook、确认、权限钩子（`installPermissions`：`permission.Load` 合并项目与用户 `GeekAgent.json` → `SetPolicy`；`SafePath` → `SetPathGuard`；`Redact` → `SetRedactor`；`ensurePolicy` 按文件 mtime 热加载）、`SetDelegator` → `chat.Delegate`、空闲 Ctrl+C
8. 创建 `plugins.Manager` 并 `Start()`：执行插件 `onStart`、注册插件工具；失败只提示，不阻断启动
9. 若为 `DesktopRunner`（GUI / Web）：REPL 进 goroutine，主线程 `Run()`；否则直接进循环
10. Banner：打印工作目录、模型、会话；GUI / Web 仅短欢迎；若有则列出已加载 `.env`
11. 会话切换（`/open` `/new` `/rename` `/delete` `/project`）经 `plan.Activate` / `Move` / `Drop` 同步任务清单；`/project` 后重新扫描技能

桌面版通过 `desktop_on.go`（`desktop` 标签）导入 `internal/gui` 完成工厂注册；Web 模式通过 `internal/webui` 注册 `KindWeb`。REPL 本身不依赖 GUI 包，侧栏数据由 `workspace` + `ui.Nav` 组装。
## 3. 斜杠命令

| 命令 | 行为 |
|------|------|
| `/` | 命令菜单（↑/↓ 选择） |
| `/model` | 模型配置菜单（↑/↓）→ 进入对应配置页；可持久化到全局 `.env` |
| `/help` | 帮助（含全局安装与 cwd 说明） |
| `/pwd` | 显示工作目录与会话路径 |
| `/status` | 工作目录 + 供应商/模型 + 已加载技能 + `Chat.Status()` |
| `/project <目录>` | 保存当前会话后切换工作目录并加载该项目会话（重新扫描技能、重载权限与 MCP） |
| `/skills` | 列出 `skills/*/SKILL.md`（`*` 为已加载），显示描述与工具白名单 |
| `/use <名称>` | 加载技能并立即生效（system 片段 + 工具白名单）；无参数等价 `/skills` |
| `/unuse [名称]` | 卸载指定技能；省略名称则全部卸载 |
| `/sessions` `/new` `/save` `/load` | 多会话 |
| `/open <id> [目录]` | 打开会话；带目录（id 后整段，可含空格）时先 `switchProject`，失败即止 |
| `/rename <新>` / `/rename <旧> <新>` | 重命名会话并保存 |
| `/delete <id>` | `ui.Confirm` 后删除并保存；删当前会话切到最近更新的另一个 |
| `/memory` | 列出当前项目 `.geekagent/memory.json` |
| `/rag` | 列出当前项目 `.geekagent/rag/index.json` 的来源与段数；`/rag clear` 确认后清空索引 |
| `/mcp` | 显示 `.geekagent/mcp.json` 中 MCP server 的连接状态与工具数；`/mcp reload` 重新读取并连接 |
| `/plugins` | 显示编译期插件、生命周期状态、命令与工具；`/plugins reload` 重新执行 `onExit` / `onStart` |
| `/echo <文本>` | 示例插件命令；内置命令未命中时再查插件命令表 |
| `/undo` | `tools.UndoLast`：弹出一条 write/patch 撤销（最多 20 条，不撤销 shell） |
| `/permissions` | 重新读取并显示项目与用户权限规则 |
| `/reset` `/compact` `/exit` | 同前 |

## 4. 工作目录语义

- `ls` / `glob` / `read` / `write` / `patch` / `run_shell` 相对进程 cwd。  
- `rag_add` / `rag_search` / `/rag` 使用当前项目 `.geekagent/rag/index.json`；`/project` 切目录后自动跟随新项目。
- MCP 使用当前项目 `.geekagent/mcp.json`；启动时连接，`/project` 关闭旧 server 并按新项目重载，`/mcp reload` 手动重连。
- 在仓库外任意项目执行 `hi-agent`，即操作该项目文件。  
- 不自动 `chdir`；用户通过「先 cd 再启动」选择项目。  

## 5. 普通对话

1. `UserEcho` → `BeginReply` → `StreamReply`（进度行走 `Progress`，正文走 `Model`）  
2. 默认折叠：工具进度并入摘要行；正文中的思考标签拆入过程块  
3. `EndReply`；中断提示不退出  
4. 对话不自动写盘（`/save` 或退出时保存）  
5. 输入行：`/` 提示命令、Tab 补全；PgUp/PgDn 滚动消息（生成中不可滚）  

## 6. 中断与退出

| 场景 | 行为 |
|------|------|
| 回复中 Ctrl+C | `NotifyContext` 取消 → `ErrInterrupted` |
| 回复中点 GUI「停止」 | `ui.Canceler` 注入的 cancel → `ErrInterrupted` |
| 空闲 Ctrl+C | 走 `exit()`：保存会话、关闭 MCP 子进程、`ui.Close()`、打印 bye、`os.Exit(0)` |
| `/exit` / EOF | 同上（无 `os.Exit`） |

## 7. 环境变量（本层）

| 变量 | 默认 | 说明 |
|------|------|------|
| `GEEKAGENT_UI` / `HI_AGENT_UI` | `tui` | `tui` / `plain` / `gui` / `web` |
| `GEEKAGENT_WEB_ADDR` | `127.0.0.1:8787` | Web 模式监听地址 |
| `GEEKAGENT_TUI` | 开启 | `0` 兼容为 plain |
| `GEEKAGENT_FOLD` | 开启 | `0` 展开工具/思考全文 |
| `GEEKAGENT_STREAM_USAGE` | 开启 | `0` 关闭 `stream_options`（兼容部分网关） |
| `GEEKAGENT_CONTEXT_WINDOW` | `128000` | 面板上下文窗口上限 |

## 8. 边界

- `historySnapshot`（GUI 重绘）按 `ToolCallID` 把工具结果配回调用，截前 300 字。  
- 主循环提示固定为 `ui.MainPrompt`；其它提示表示命令在索取参数（GUI 据此锁侧栏）。  
- `/load` 覆盖未保存改动。  
- 技能加载状态只在进程内；换项目后按新目录重新扫描，同名技能保持加载、不存在的自动丢弃。  
- 插件生命周期只在启动、`/plugins reload` 和退出时执行；切换项目不重启插件，插件通过 `Context.WorkDir()` 跟随新目录。
- UI 创建失败或 TUI 启动失败自动回退 plain。
