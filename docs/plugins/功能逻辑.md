# plugins — 功能逻辑

## 1. 职责

编译期插件框架：用 Go 包替代 TS 的 `plugins/*/plugin.ts` 动态扫描。插件在 `init()` 中向 `internal/plugins` 注册声明，REPL 启动时执行 `onStart`，退出时执行 `onExit`；内置斜杠命令未命中时再交给插件命令表。

代码：

| 位置 | 说明 |
|------|------|
| `internal/plugins/plugins.go` | `Register`、`Plugin` / `Command` / `Context`、`Manager`、命令分派 |
| `plugins/echo/plugin.go` | 示例：`/echo` 回显 |
| `plugins/web/plugin.go` | 示例：`/web` 提示 Web 模式入口 |
| `plugins/all/all.go` | 汇总插件；`cmd/hi-agent` 空白导入完成编译期注册 |
| `cmd/hi-agent/main.go` | 创建 `Manager`、执行生命周期、`/plugins`、插件命令回退 |

## 2. 注册与生命周期

```go
type Plugin struct {
    Name        string
    Description string
    Commands    []Command
    Tools       []tools.Tool
    OnStart     func(*Context) error
    OnExit      func(*Context) error
}
```

1. 插件包的 `init()` 调用 `plugins.Register`；重名插件、跨插件重名命令、空命令回调会 panic（启动期失败）。
2. `plugins/all` 只做空白导入；新增插件时在 `plugins/all/all.go` 添加一行。
3. REPL 在权限、MCP 初始化之后调用 `Manager.Start()`：按插件名顺序执行 `OnStart`，成功后再注册 `Plugin.Tools`。
4. `OnStart` 内可用 `ctx.RegisterTool` 注册动态工具；`Manager` 记录工具名，`Close` 时统一注销。
5. `Manager.Close()` 逆序执行 `OnExit` 并注销工具；`/plugins reload` 等价于 `Close` + `Start`。
6. 单个插件启动失败只记录到 `/plugins` 状态，不阻断其它插件和对话。

## 3. 命令分派

- REPL 先走内置 `switch`；`default` 分支才调用 `Manager.Run(cmd, args)`。
- 命令名统一小写、去掉前导 `/`；`/echo` 与 `/ECHO` 都可命中。
- 未命中返回 `handled=false`，REPL 再打印“未知命令”。
- 插件命令出现在 `slashCommands()` 的补全列表和 `/help` 的“插件命令”行。
- `/plugins` 显示插件状态、命令与声明的工具；`/plugins reload` 重新执行生命周期。

## 4. Context

插件不直接依赖 REPL，只拿到受限的 `Context`（别名 `PluginContext`）：

| 方法 | 说明 |
|------|------|
| `WorkDir()` | 当前项目目录；`/project` 后自动跟随 |
| `Info` / `Error` | 输出到当前 UI（TUI / plain / GUI / Web） |
| `Confirm` | 请求用户确认 |
| `RegisterTool` | 注册工具并由 `Manager` 跟踪注销 |
| `Plugin()` | 当前插件名 |

`Host` 由 `cmd/hi-agent` 的 `pluginHost` 实现；注册工具时把 `tools.Register` 的 panic 转成错误，避免插件启动时崩溃。

## 5. 边界

- 不做运行时动态加载 / 热插拔；插件必须编进二进制。
- 插件工具默认走 Day 8 权限策略：未写入默认 allow 的工具默认 `deny`，需要 `GeekAgent.json` 放行。
- 生命周期只在进程启动、`/plugins reload`、退出时执行；切换项目不重启插件。
- 插件命令的执行线程与 REPL 相同，不应长时间阻塞；需要长任务应自行起 goroutine 并只通过 UI 回调汇报。
