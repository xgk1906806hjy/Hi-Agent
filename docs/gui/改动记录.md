# gui — 改动记录

## 2026-10-12 — Fyne 桌面对话壳初建

- 新增 `internal/gui`：Shell（聊天区/侧栏/输入/斜杠按钮）、Confirm/Select 对话框、`StatusSnapshot`。
- `internal/ui` 注册 `KindGUI` 适配器与 `DesktopRunner`；REPL 在 GUI 模式下主线程 Run、循环进 goroutine。
- 影响范围：`internal/gui/*`、`internal/ui/{gui_factory,ui,factory}.go`、`cmd/hi-agent/main.go`、文档与 `.env.example`。

## 2026-10-12 — 双击版 exe + 停止按钮

- 新增 `scripts/build-gui.{ps1,sh}`：打包默认进 GUI、无控制台的可执行文件（`dist/`），可选建桌面快捷方式。
- Shell 增加「停止」按钮与 `SetCancel`，替代无控制台时的 Ctrl+C。
- 影响范围：`internal/gui/shell.go`、`scripts/build-gui.*`。

## 2026-10-12 — Codex 风格改版

- 新增 `theme.go`（浅色中性 + 蓝强调）、`message.go`（用户/助手/工具气泡）。
- 侧栏改为紧凑字段；底部斜杠仅 `/model` `/sessions` `/help`；顶栏显示品牌·模型。
- REPL GUI banner 缩短为两行欢迎。
- 影响范围：`internal/gui/*`、`cmd/hi-agent/main.go`、`docs/gui/*`。

## 2026-10-12 — 左侧项目与会话

- 左侧栏：项目列表（+ 选文件夹）、当前项目的会话列表（+ 新建）。
- 项目路径持久化 `~/.hi-agent/projects.json`；切换走 `/project`（先保存再 chdir 并重载会话）。
- 影响范围：`internal/gui/{nav,projects,shell}.go`、`cmd/hi-agent/main.go`。

## 2026-10-12 — 视觉收干净

- 侧栏与快捷改为无边框文字行（`tapRow`），去掉默认大按钮。
- 用户消息浅蓝圆角气泡；输入区白底圆角条；发送改为图标按钮，停止仅在生成时出现。
- 影响范围：`internal/gui/{row,theme,message,nav,shell,status}.go`。

## 2026-10-13 — Wails + React 替换 Fyne

- 删除全部 Fyne 实现与依赖；新增 `protocol.go` / `adapter.go`（无 tag）与 `app.go` / `register.go`（`desktop` tag）。
- 前端：Vite + React + Tailwind；`bridge`（wails/mock）与单一 store；Markdown / 工具折叠 / 项目会话树。
- 项目注册表迁至 `internal/workspace`；REPL 只依赖 `ui` / `workspace`。
- 构建：`scripts/build-gui.*` 先 `npm` 再 `go build -tags desktop,production`。
- 影响范围：`internal/gui/**`、`internal/ui`、`internal/workspace`、`cmd/hi-agent`、`scripts/build-gui.*`、文档与 README。

## 2026-10-13 — 修复「添加项目」不可用

- 生产环境禁止 silent mock（误连 mock 时 `addProject` 为空操作）；拉长 Wails 就绪等待。
- `AddProject`：选中后必 `workspace.Remember` + `RefreshNav`；同目录也登记；对话框错误可见。
- `Adapter.Refresh` 同时刷新 nav；导出 `RefreshNav`。
- mock（仅 npm run dev）用 prompt 模拟添加项目。
- 影响范围：`internal/gui/{app,adapter}.go`、`frontend/src/bridge/*`、`store`、`App.tsx`。

## 2026-10-13 — GUI 收尾：侧栏锁、会话管理、补全、深色、拆包

- 侧栏锁：`Adapter.Idle()`（仅阻塞在 `ui.MainPrompt` 时为真）+ `App.requireIdle()` 兜底；前端未连接/生成中/等待参数时禁用侧栏。store 不再把空 prompt 当成主提示。
- 会话元数据：协议 `NavSessionPayload` 增 `title`、`updatedAt`（毫秒）；侧栏两行显示并按时间倒序。
- 会话操作：`RenameSession` / `DeleteSession` 绑定 → `/rename` `/delete`；侧栏 hover 行内重命名、删除。
- 跨项目打开改为单条 `/open <id> <目录>`。
- 斜杠补全：`Config.Slash` → `Snapshot.slash`；Composer 弹出列表（↑/↓、Tab/Enter、Esc）。
- 深色模式（CSS 变量 + hljs 深色配色 + prose 变量）；Markdown 懒加载，主包 566 KB → 246 KB。
- 单测：`Idle` 仅主提示为真、Snapshot 携带 slash 与会话元数据。
- 影响范围：`internal/gui/{adapter,app,protocol,register}.go`、`frontend/src/{bridge,store,components}/*`、`index.css`。

## 2026-10-13 — 权限、任务、diff 与深色底色

- 顶栏「权限」展示 `status.policy`；侧栏在有任务时显示清单。
- 未保存会话（`updatedAt` 为 0）排在有更新时间的会话之后，点开不会置顶。
- 确认框里的 diff 行按增删着色；对话框加宽。
- 窗口背景色跟随 Windows 应用主题（`AppsUseLightTheme`），减轻深色启动闪白。
- 影响范围：`internal/gui/{app,protocol,window_bg_*}.go`、`frontend` 的 TopBar / Sidebar / ConfirmDialog / index.css。

## 2026-10-13 — 主题开关与跨项目会话操作

- 顶栏在跟随系统、浅色、深色之间循环；选择写入 `localStorage`，深色由 `html.dark` 控制。`SetTheme` 同步原生窗口背景色。
