# gui — 功能逻辑

## 1. 职责

基于 **Fyne v2** 的桌面原生对话壳（**非浏览器**、非 WebView）：主聊天区 + 右侧状态侧栏 + 底部输入与斜杠快捷按钮。通过 `internal/ui` 的 `KindGUI` 适配器接入现有 REPL，不重写业务循环。

代码：`internal/gui/`（`shell.go`、`dialogs.go`、`status.go`）。

## 2. 启动与线程模型

1. `GEEKAGENT_UI=gui`（或 `HI_AGENT_UI=gui`）→ `ui.Create(KindGUI)` → `gui.New` 建窗（尚未 Run）。
2. `main` 检测 `ui.DesktopRunner`：REPL（`bannerAndLoop`）进 **goroutine**；主线程调用 `Run()`（Windows 上 Fyne 要求主线程跑 UI）。
3. 窗口关闭或 `/exit` → `Done` 解除 `ReadLine` 阻塞 → `exit()` → `Quit`。

## 3. 布局

```
+---------------------------+----------------+
| 消息流（用户/助手/过程）   | 状态侧栏       |
|                           | 模型/会话/目录 |
|                           | tokens/工具    |
+---------------------------+----------------+
| 斜杠快捷 | 输入框 + 发送                    |
```

消息样式：系统 / 用户 / 助手流式 / 工具过程 / 错误。侧栏数据来自 `Options.StatusFn` → `StatusSnapshot`（与 TUI Panel 字段对齐，gui 不依赖 `tui` 类型）。

## 4. UI 契约映射

| `ui.UI` | GUI 行为 |
|---------|----------|
| `ReadLine` | 阻塞等输入栏/斜杠按钮提交 |
| `Confirm` / `Select` | Fyne 模态对话框，channel 回传 |
| `Info`/`Notice`/`Error`/`UserEcho`/`Progress`/`Model` | `fyne.Do` 追加到聊天区 |
| `BeginReply`/`EndReply`/`Refresh` | 忙态与侧栏刷新 |
| `Close` | `Quit` 关窗 |

## 5. 环境变量

| 变量 | 值 | 说明 |
|------|-----|------|
| `GEEKAGENT_UI` / `HI_AGENT_UI` | `gui` | 启用本模块 |

## 6. 边界

- 首版不做：文件树、代码编辑器、diff 内嵌、WebUI。
- 无头/CI 不宜启动真实窗口；单元测侧重 `StatusSnapshot` 与工厂注册。
- 斜杠命令字符串仍走 REPL `handleCommand`，GUI 只提交等价行。
