# gui — 功能逻辑

## 1. 职责

基于 **Fyne v2** 的桌面原生对话壳（**非浏览器**、非 WebView），观感对标 **Codex 桌面版**：简洁对话窗（气泡、紧凑侧栏、少按钮），不做 Cursor 全 IDE。

代码：`internal/gui/`（`shell.go`、`message.go`、`theme.go`、`dialogs.go`、`status.go`）。

## 2. 启动与线程模型

1. `GEEKAGENT_UI=gui`（或 `HI_AGENT_UI=gui`）→ `ui.Create(KindGUI)` → `gui.New` 建窗（尚未 Run）。
2. `main` 检测 `ui.DesktopRunner`：REPL（`bannerAndLoop`）进 **goroutine**；主线程调用 `Run()`（Windows 上 Fyne 要求主线程跑 UI）。
3. 窗口关闭或 `/exit` → `Done` 解除 `ReadLine` 阻塞 → `exit()` → `Quit`。

### 双击版 exe

- `scripts/build-gui.ps1` 生成 `dist/Hi-agent.exe`：`-H=windowsgui`（无控制台）+ `-X main.defaultUI=gui`。`-Desktop` 可复制到桌面。
- 工作目录：双击时为 exe 所在目录；快捷方式为「起始位置」；把文件夹拖到 exe 上则以该文件夹为工作区。
- 无控制台时配置缺失不退出：`config.LoadE` 返回错误，窗口内提示用 `/model` 配置。
- 输入栏旁「停止」按钮（`ui.Canceler`）。

## 3. 布局（Codex 向）

```
+----------+-------------------------------+-------------+
| 项目  +  | Hi-agent · <model>            | 状态/模型   |
|  当前项目 | 用户气泡 / Agent / 工具过程   | 目录/tokens |
| 会话  +  |                               |             |
|  当前会话 |                               |             |
+----------+-------------------------------+-------------+
| [/model] [/sessions] [/help]  输入 [停止][发送]       |
```

- 左侧「项目 +」打开文件夹选择，记入 `~/.hi-agent/projects.json`，并 `/project` 切换工作目录（会话按项目目录的 `.geekagent/` 分开）。
- 左侧「会话 +」等价 `/new`；点击会话等价 `/open`。

- 主题：`codexTheme` 浅灰底、蓝色强调发送按钮。
- 底部斜杠只展示白名单三枚；其余命令可输入框输入。
- GUI 启动 banner 仅 2 行欢迎，不自动灌 `/help` 全文。

## 4. UI 契约映射

| `ui.UI` | GUI 行为 |
|---------|----------|
| `ReadLine` | 阻塞等输入栏/斜杠按钮提交 |
| `Confirm` / `Select` | Fyne 模态对话框，channel 回传 |
| `Info`/`Notice`/`Error`/`UserEcho`/`Progress`/`Model` | `fyne.Do` 追加气泡 |
| `BeginReply`/`EndReply`/`Refresh` | 忙态与侧栏/顶栏刷新 |
| `SetCancel`（`ui.Canceler`） | 回复中启用「停止」 |
| `Close` | `Quit` 关窗 |

## 5. 环境变量

| 变量 | 值 | 说明 |
|------|-----|------|
| `GEEKAGENT_UI` / `HI_AGENT_UI` | `gui` | 启用本模块 |

## 6. 边界

- 不做：文件树、代码编辑器、diff 内嵌、WebUI、WebView。
- 无头/CI 不宜启动真实窗口；单元测侧重 `StatusSnapshot`。
- 斜杠命令字符串仍走 REPL `handleCommand`。
