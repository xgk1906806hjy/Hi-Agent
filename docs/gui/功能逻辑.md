# gui — 功能逻辑

## 1. 职责

基于 **Wails v2 + React + Tailwind** 的桌面对话壳（系统 WebView，单 exe）。视觉方向「精密纸面」：左侧「项目 > 会话」树、中间 Markdown 对话流、底部输入条、无边框自定义标题栏（菜单 / 状态 / 窗控）。

代码：`internal/gui/`（协议 / 适配器无构建标签；Wails 绑定与 `frontend/` 仅在 `desktop` 标签下编入）。设计探索稿在仓库 `design-demos/`（不编入二进制）。
## 2. 分层

| 层 | 文件 | 说明 |
|----|------|------|
| 协议 | `protocol.go` | 事件名与载荷；与 `frontend/src/bridge/types.ts` 同步 |
| 适配器 | `adapter.go` | 实现 `ui.UI` + `DesktopRunner` + `Canceler`；依赖窄接口 `Emitter` |
| Wails | `app.go` / `register.go`（`//go:build desktop`） | `wails.Run`、embed 前端、`ui.Register(KindGUI)`、系统文件夹对话框 |
| 前端 | `frontend/` | Vite + React；`bridge/`（wails / mock）、`store/`、组件 |

依赖方向：`cmd/hi-agent` → `ui` / `workspace`；**不** import `gui`。桌面包在 `desktop` 标签下反向 `Register` 覆盖占位工厂。

## 3. 启动与线程

1. 带 `desktop` 标签构建的 exe（或 `GEEKAGENT_UI=gui`）→ `ui.Create(KindGUI)` → `Adapter`。
2. `main` 检测 `DesktopRunner`：REPL 进 goroutine；主线程 `Run()` → `wails.Run`。
3. 前端挂载后调 `Ready()` → `Attach(Emitter)`，冲刷启动前排队的事件（避免丢 banner）。
4. 关窗 / `/exit` → `Closed()` → `ReadLine` 返回 EOF。

### 双击版 exe

- `scripts/build-gui.ps1`：`npm ci && npm run build` → `go build -tags desktop,production -ldflags "-H=windowsgui -X main.defaultUI=gui"` → `dist/Hi-agent.exe`。`-Desktop` 可复制到桌面。
- Windows 任务栏/窗口图标：`cmd/hi-agent/rsrc_windows_amd64.syso`（资源 ID 3，对应 `build/appicon.ico`）；前端标题栏用 `AppIcon` SVG。
- 普通 `go install ./cmd/hi-agent` **不含**桌面界面（占位错误提示用 build-gui 构建）。
- 无控制台时配置缺失不退出：`config.LoadE`；窗口内提示 `/model`。
- 「停止」按钮经 `ui.Canceler`。

## 4. 布局

```
+------------------------------------------+
| ● Hi-agent  File Edit View Help   [窗控] |
+----------+-------------------------------+
| 项目  +  | 用户气泡 / Markdown / 工具折叠 |
|  会话树  |                               |
+----------+-------------------------------+
| [/model] [/sessions] [/help]  输入 [停/发] |
```

- 无边框窗口 + 自定义标题栏（方案 2 合并单层）：黑色 Orbit 图标、File/Edit/View/Help、会话/主题/模型胶囊、最小化/最大化/关闭。拖拽标题栏空白处移动窗口。

- 「项目 +」→ 系统文件夹对话框 → `/project <dir>`；登记在 `~/.hi-agent/projects.json`（`workspace` 模块）。项目按登记顺序排列：新添加的项目在最前，点开已登记项目不再置顶。
- 「会话 +」→ `/new`；点会话 → `/open <id>`，跨项目发一条 `/open <id> <目录>`（REPL 先切项目，失败即止）。
- 会话行两行显示：标题（首条用户消息，空则 ID）+ 相对时间 · N 条；按 `updatedAt` 倒序，未保存的在最后。点开或切换会话不改这个时间，列表不会把刚点的那条顶上去。
- 任意项目的会话 hover 都显示「重命名」和「删除」。当前项目仍提交 `/rename`、`/delete`（内存里的会话管理器与磁盘一致）。其它项目直接改那个目录的 `.geekagent/sessions.json`，并同步挪动或删掉该会话的任务清单。
- 侧栏在「任务」卡片下方显示「技能」卡片（`status.skills`），按 `/use` 之后即时刷新；没有已加载技能时不占位。
- **侧栏锁**：未连接、生成中、或 REPL 正在等某条命令的参数（提示 ≠ `ui.MainPrompt`）时侧栏全部禁用；Go 侧 `App.requireIdle()` 再兜底（`Adapter.Idle()` 仅在主提示阻塞时为真），避免点击被当作 API Key 等输入。
- Enter 发送，Shift+Enter 换行；生成中发送键变停止。
- 输入以 `/` 开头且无空格时弹出斜杠命令补全（列表来自 `Snapshot.slash`，即 REPL 的 `slashCommands()`）：↑/↓ 选择，Tab/Enter 补全，Esc 关闭。
- 连续工具进度合并为可折叠「过程」块（单行紧凑条：状态图标 + 「过程」+ 数量 + 最后一步预览）；`<think>` / `<thinking>` / `<reasoning>` 从正文拆出。两者**默认折叠**，运行中也不自动展开，点击摘要才查看明细；切会话重绘时工具调用带结果前 300 字。
- 主题三态，记在 `localStorage` 的 `hi-agent-theme`：`system`（默认）、`light`、`dark`。顶栏按钮循环切换。深色由 `html.dark` 打开；跟随系统时按 `prefers-color-scheme` 决定。`App.SetTheme` 把原生窗口背景改成与页面一致。
- 视觉方向「精密纸面」：浅暖灰底、Inter + JetBrains Mono、细线圆角卡片、用户气泡浅蓝、输入区浮起阴影。深色是同一套暖中性色。
- 打包：Markdown（react-markdown + highlight）`React.lazy` 拆成独立 chunk，首屏只加载外壳。

## 5. Go ↔ 前端协议（节选）

| 方向 | 名称 | 含义 |
|------|------|------|
| → FE | `chat:user` / `chat:delta` / `chat:progress` / `chat:info` / `chat:notice` / `chat:error` | 对话与提示 |
| → FE | `chat:reset` | 切换项目/会话后重绘 |
| → FE | `turn:begin` / `turn:end` | 忙态 |
| → FE | `status` / `nav` | 顶栏与侧栏（`status.skills` 为已加载技能名） |
| → FE | `dialog:confirm` / `dialog:select` | 模态对话框 |
| → FE | `input:prompt` | REPL 等待输入时的提示语 |
| ← FE | `Submit` / `Stop` / `Answer` / `AddProject` / `OpenProject` / `RemoveProject` / `OpenSession` / `NewSession` / `RenameSession` / `DeleteSession` / `Ready` | 绑定方法 |

`Snapshot` = `{status, nav, prompt, slash}`；`nav` 中会话含 `title`、`updatedAt`（Unix 毫秒，0 表示未落盘）。`prompt` 为空表示 REPL 正在处理（非空闲）。

## 6. 环境变量与构建

| 变量 | 值 | 说明 |
|------|-----|------|
| `GEEKAGENT_UI` / `HI_AGENT_UI` | `gui` | 启用桌面界面（须桌面版二进制） |

| 前置 | 说明 |
|------|------|
| Node 18+ | 仅打包前端时需要 |
| Windows | WebView2（Win10/11 通常自带） |
| Linux | `webkit2gtk` |
| 开发预览 | `cd internal/gui/frontend && npm run dev`（mock bridge，不连 Go） |

## 7. 边界

- 不做：文件树、代码编辑器、diff 内嵌、纯 Web 服务端。
- 无头/CI：不启真实窗口；单测覆盖 adapter（假 Emitter）与 protocol 载荷。
- 斜杠命令仍走 REPL `handleCommand`。
