# tui — 功能逻辑

## 1. 职责

轻量全屏终端界面：左侧消息区、右侧状态面板、底部输入行。  
输入在 `ReadLine`/`Select` 时切 raw mode；渲染用 ANSI 绝对定位整屏重绘。  
本包是 **UI 实现之一**，由 `internal/ui` 工厂以 `KindTUI` 注册；REPL 不直接依赖本包创建流程。

## 2. 代码位置

| 文件 | 说明 |
|------|------|
| `tui.go` | `TUI` 生命周期、消息追加、节流重绘、读行与确认 |
| `input.go` | raw 输入、斜杠提示/Tab 补全、PgUp/PgDn 滚动 |
| `select.go` | ↑/↓ 选择菜单（`Select`） |
| `fold.go` | 过程折叠摘要与 `GEEKAGENT_FOLD` |
| `think.go` | 流式拆分 `<think>` 等思考标签 |
| `panel.go` | 右侧面板文案与进度条 |
| `layout.go` | 显示宽度、折行、截断（CJK 按 2 列） |
| `vt_windows.go` / `vt_other.go` | Windows 启用 VT 处理 |

## 3. 布局

```
┌─────────────────────────────┬────────────────┐
│ 消息区（可滚动尾部）         │ 右侧面板       │
│                             │ 模型/会话/状态 │
│                             │ 上下文进度条   │
│                             │ 本轮/累计 tokens│
├─────────────────────────────┴────────────────┤
│ 分隔提示行                                   │
│ You › 输入…                                  │
└──────────────────────────────────────────────┘
```

- 终端宽 ≥ 80：右侧固定 34 列；否则隐藏面板，消息区占满。  
- 可视行 = 终端高 − 2（提示行 + 输入行）。  
- 消息区可 **鼠标滚轮** / **PgUp/↑** 上翻、**PgDn/↓** 下翻（内部 scrollOff；备用屏无系统回滚）。  
- 输入以 `/` 开头时，提示行显示匹配命令；**Tab** 补全。  
- `ReadLine` 期间开启 SGR 鼠标上报（`1000h`+`1006h`），滚轮一格约 3 行。  

## 4. 生命周期

1. `Supported()`：stdin 与 stdout 均为 TTY。  
2. `Start()`：启用 VT → 进入备用屏幕 `\x1b[?1049h` → 清屏 → 首次 `Flush`。  
3. `ReadLine`：`MakeRaw` 逐键编辑（显示 `inputBuf`、斜杠提示、滚动）；结束后 Restore。  
4. 运行中：`Model`/`Progress`/`Info` 等修改 entries → `Refresh`（节流 40ms）或 `Flush`。  
5. `Close()`：复位颜色、显示光标、退出备用屏幕、恢复 ConsoleMode（可重复调用）。  

## 5. 消息写入

| 方法 | 行为 |
|------|------|
| `UserEcho` | 追加用户行（先关开流段落） |
| `Model` | 追加/合并流式模型正文；`<think>` / `<thinking>` / `<reasoning>` 段拆入折叠块 |
| `Progress` | 工具/压缩/护栏进度；默认并入单一折叠摘要行 |
| `Info` / `Notice` / `Error` | 系统 / 提示 / 错误（确认 diff 走 Notice，不折叠） |
| `BeginReply` / `EndReply` | 面板「生成中」；结束时将过程块标为「已折叠」 |

### 5.1 过程折叠

- 默认开启；`GEEKAGENT_FOLD=0` 关闭，恢复逐行全文展示。  
- 折叠块仅显示摘要，例如：`▸ 工具×3 · 思考（已折叠）`；完整内容存在 `detail` 不渲染。  
- 正文开始或 `EndReply` 时收拢当前过程块。  
- `Confirm` 的 diff 仍完整展示（需用户审阅）。

## 6. 面板数据

由调用方 `panel func() Panel` 每帧提供：模型、会话、工作目录、上下文 tokens、历史字符、本轮/累计用量、工具轮次。  
`Busy` 由 TUI 自身根据 Begin/End 覆盖。

## 7. 边界

- 不用 bubbletea / tview 等框架。  
- 确认 diff 写入消息区后再在输入行问 y/N（与 Day3 语义一致）。  
- 窄终端自动隐藏右栏。  
- 非 TTY 或 `GEEKAGENT_TUI=0` 时 REPL 不创建本模块。  
- 折叠块暂不支持交互展开；需要全文时设 `GEEKAGENT_FOLD=0`。  
- 生成中（busy）暂不能滚动；回复结束后在输入行用 PgUp 上翻。
