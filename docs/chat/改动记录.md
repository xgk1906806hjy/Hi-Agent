- 依赖 `internal/tools`；缺 id 补 `call_N`；失败回滚至本轮 user 入队前。
- 影响范围：`internal/chat/chat.go`。

## 2026-09-29 — Day5 历史压缩

- 新增 `compact.go`：超阈值自动摘要；保留最近 6 条；`Compact()` 供 `/compact`。
- 阈值默认 4000，可用 `GEEKAGENT_MAX_HISTORY` 覆盖。
- 切分避开 orphan `tool` 消息；失败回滚用整段 snapshot。
- 影响范围：`internal/chat/{chat,compact}.go`。

## 2026-09-29 — 工具轮次用尽改为强制收尾

- 不再输出「已停止」中断；达上限后 `tool_choice=none` 再请求一轮作答。
- 收尾请求失败时回落为友好提示文本，会话可继续。
- 影响范围：`internal/chat/chat.go`；REPL 识别 `\n[工具轮次` 进度色。

## 2026-09-29 — 工具循环护栏优化（P0）

- 轮次上限可配：`GEEKAGENT_MAX_TOOL_TURNS`（默认 8）。
- 同工具同参连续熔断：`GEEKAGENT_MAX_DUP_TOOLS`（默认 3），触发后强制收尾。
- 收尾前注入临时总结 system（对齐 OpenCode），不写入持久 history。
- 方案见 `doc/工具循环优化方案.md`。
- 影响范围：`internal/chat/{chat,loop_config}.go`、REPL 进度色、`/help`。
