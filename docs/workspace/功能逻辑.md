# workspace 模块：功能逻辑

代码：`internal/workspace/`

## 职责

- **项目注册表**：用户登记过的项目目录列表，存于 `~/.hi-agent/projects.json`（`{"projects":[...]}`），最近使用的在最前。
- **会话列表**：只读解析某项目下 `.geekagent/sessions.json`，返回每个会话的 ID、标题（首条用户消息，同 `session.TitleFromText`）、消息数、`UpdatedAt`、是否当前会话。

不依赖任何界面包（`ui` / `gui` / `tui`）。REPL 用它组装 `ui.Nav`，桌面界面只消费结果。

## API

| 函数 | 说明 |
|------|------|
| `RegistryPath()` | 注册表文件路径；取不到主目录时为空 |
| `Load()` | 读取项目列表；文件缺失或损坏返回空 |
| `Remember(dir)` | 登记目录到最前（已存在则前移，Windows 忽略大小写去重） |
| `Remove(dir)` | 从列表移除目录 |
| `ListSessions(dir)` | 只读列出 `dir` 下会话，按 ID 排序 |
| `SamePath(a, b)` / `Name(path)` | 路径比较、侧栏显示名 |

## 注意

- `ListSessions` 不写文件、不经过 `session.Manager`，因此对当前项目，REPL 应以内存中的 `Manager.SessionBriefs()` 为准（可能有未保存的消息）。
- 注册表是用户级状态，不在仓库内。
