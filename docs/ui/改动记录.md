# ui — 改动记录

## 2026-10-12 — UI 抽象工厂初建

- 新增 `internal/ui`：`UI` 接口、`Register`/`Create`/`ResolveKind`；内置 plain、tui；预留 gui/web。
- REPL 改为经工厂创建界面；删除 `cmd/hi-agent/ui.go`。
- 影响范围：`internal/ui/*`、`cmd/hi-agent/main.go`、`docs/*`、`AGENTS.md`。

## 2026-10-12 — KindGUI（Fyne）接入

- 新增 `gui_factory.go`：`Register(KindGUI)`、通道适配器、`DesktopRunner`；`Options.StatusFn`。
- 去掉 GUI 的 notImplemented stub；web 仍预留。
- 影响范围：`internal/ui/*`、`docs/ui/*`。

## 2026-10-12 — Canceler 可选接口

- 新增 `ui.Canceler`（`SetCancel`）：界面自带停止按钮时由 REPL 注入取消函数；GUI 适配器实现。
- 影响范围：`internal/ui/{ui,gui_factory}.go`。

## 2026-10-12 — NavFn

- `Options.NavFn`（`func() gui.NavSnapshot`）传给 GUI 左侧项目/会话。
- 影响范围：`internal/ui/{ui,gui_factory}.go`。

## 2026-10-13 — 强类型视图 + GUI 占位

- 新增 `view.go`：`Status` / `Nav` / `Turn`；`Options.StatusFn` / `NavFn` / `HistoryFn` 改为强类型函数。
- 删除 `gui_factory.go`；`factory.go` 为 `KindGUI` 注册占位（提示用 build-gui 构建），桌面包覆盖。
- 影响范围：`internal/ui/*`、`cmd/hi-agent`、`internal/gui`。

## 2026-10-13 — MainPrompt 与会话元数据

- 新增 `MainPrompt`（REPL 主提示）；界面据此区分「空闲」与「命令正在索取参数」。
- `NavSession` 增加 `Title`、`UpdatedAt`。
- 影响范围：`internal/ui/{ui,view}.go`；`cmd/hi-agent`、`internal/gui`。

## 2026-10-13 — 状态增加权限与任务

- `Status.Policy`、`Status.Todos` / `Todo`，供桌面顶栏与侧栏。
- 影响范围：`internal/ui/view.go`、`internal/gui/protocol.go`。

## 2026-10-23 — 状态增加已加载技能

- `Status.Skills []string`：当前进程已加载的技能名，供桌面侧栏展示。
- 影响范围：`internal/ui/view.go`、`internal/gui/protocol.go`、`cmd/hi-agent`。
