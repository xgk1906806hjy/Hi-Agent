# ui — 功能逻辑

## 1. 职责

可插拔的**用户界面抽象与工厂**：REPL / Agent 只依赖 `UI` 接口，不绑定具体渲染技术。  
已实现 `plain`、`tui`、`gui`；预留 `web`，可通过 `Register` 扩展。

## 2. 代码位置

| 文件 | 说明 |
|------|------|
| `ui.go` | `UI` 接口、`Kind`、`Options`、`SlashCmd`、`DesktopRunner` |
| `factory.go` | `Register` / `Create` / `ResolveKind` / `ListKinds` |
| `plain.go` | 纯文本实现 |
| `tui_factory.go` | 适配 `internal/tui` 并注册 `KindTUI` |
| `gui_factory.go` | 适配 `internal/gui` 并注册 `KindGUI` |
| `factory_test.go` | 工厂与 Kind 测试 |

## 3. 抽象接口

```go
type UI interface {
    Info / Notice / Error / UserEcho
    Progress / Model / BeginReply / EndReply / Refresh
    ReadLine / Confirm / Select / Close
}
```

后续 GUI、WebUI 实现同一接口即可接入，无需改 REPL 主循环。

## 4. 工厂

| API | 说明 |
|-----|------|
| `Register(kind, FactoryFunc)` | 注册/覆盖实现（扩展点） |
| `Create(kind, Options)` | 按 Kind 创建 |
| `MustCreate` | 失败回退 plain |
| `ResolveKind()` | 读环境变量决定 Kind |
| `ListKinds()` | 已注册列表 |

`Options`：`In`、`SlashCommands`；`PanelFn` 仅 TUI（`func() tui.Panel`）；`StatusFn` 仅 GUI（`func() gui.StatusSnapshot`）。  
`DesktopRunner`：GUI 额外提供阻塞 `Run()`，由 `main` 在主线程调用。

## 5. Kind 与环境变量

| Kind | 状态 | 说明 |
|------|------|------|
| `plain` | 已实现 | 纯文本 |
| `tui` | 已实现 | 全屏终端 |
| `gui` | 已实现 | Fyne 桌面壳（见 `docs/gui/`） |
| `web` | 预留 | 未实现，Create 返回明确错误 |

解析顺序：

1. `GEEKAGENT_UI` / `HI_AGENT_UI`（`tui`/`plain`/`gui`/`web`）  
2. `GEEKAGENT_TUI=0` → `plain`（兼容）  
3. 默认 `tui`

## 6. 扩展方式

```go
ui.Register(ui.KindGUI, func(opts ui.Options) (ui.UI, error) {
    return newMyGUI(opts), nil
})
```

在 `main` 的 `import _ "..."` 或本包 `init` 中注册后，设 `GEEKAGENT_UI=gui` 即可切换。

## 7. 边界

- GUI 控件在 `internal/gui`；本包只做适配注册。Web 仍预留。  
- TUI 细节仍在 `internal/tui`；本包只做适配注册。  
- `Select` 在 plain 下退化为序号输入。
