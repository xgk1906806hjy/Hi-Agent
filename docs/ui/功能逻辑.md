# ui — 功能逻辑

## 1. 职责

可插拔的**用户界面抽象与工厂**：REPL / Agent 只依赖 `UI` 接口，不绑定具体渲染技术。  
已实现 `plain`、`tui`；`gui` 由 `internal/gui` 在 `desktop` 构建标签下注册；预留 `web`。

## 2. 代码位置

| 文件 | 说明 |
|------|------|
| `ui.go` | `UI` 接口、`Kind`、`Options`、`SlashCmd`、`DesktopRunner`、`Canceler` |
| `view.go` | 强类型视图数据：`Status` / `Nav` / `Turn` |
| `factory.go` | `Register` / `Create` / `ResolveKind`；`KindGUI` 占位与 `KindWeb` 未实现 |
| `plain.go` | 纯文本实现 |
| `tui_factory.go` | 适配 `internal/tui` 并注册 `KindTUI` |
| `factory_test.go` | 工厂与 Kind 测试 |

本包**不** import `gui`；桌面实现通过依赖反转在 `desktop` 标签下 `Register` 覆盖占位。

## 3. 抽象接口

```go
type UI interface {
    Info / Notice / Error / UserEcho
    Progress / Model / BeginReply / EndReply / Refresh
    ReadLine / Confirm / Select / Close
}
```

后续 GUI、WebUI 实现同一接口即可接入，无需改 REPL 主循环。

## 4. Options 与桌面扩展

| 字段 | 用途 |
|------|------|
| `In` / `SlashCommands` | 通用 |
| `PanelFn` | 仅 TUI：`func() tui.Panel` |
| `StatusFn` | `func() Status`，桌面顶栏/状态 |
| `NavFn` | `func() Nav`，左侧项目 > 会话树 |
| `HistoryFn` | `func() []Turn`，切换会话后重绘对话流 |

`DesktopRunner`：额外阻塞 `Run()`，由 `main` 在主线程调用。  
`Canceler`（可选）：`SetCancel(func())`，供「停止」按钮。

## 5. Kind 与环境变量

| Kind | 状态 | 说明 |
|------|------|------|
| `plain` | 已实现 | 纯文本 |
| `tui` | 已实现 | 全屏终端 |
| `gui` | 桌面版二进制 | Wails 壳；终端版仅占位错误 |
| `web` | 预留 | Create 返回明确错误 |

解析顺序：`GEEKAGENT_UI` / `HI_AGENT_UI` → `GEEKAGENT_TUI=0` → 默认 `tui`。

## 6. 边界

- GUI 控件与前端在 `internal/gui`；本包只定义契约与工厂。  
- TUI 细节在 `internal/tui`。  
- `Select` 在 plain 下退化为序号输入。
