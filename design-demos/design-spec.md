# Hi-agent 桌面壳 · 设计 Spec（仅观感）

## 产品
本地桌面 AI coding agent（Wails）。左：项目 > 会话；中：Markdown 对话；底：输入；顶：模型/主题/权限。

## 受众与场景
开发者长时间盯屏。要能快速扫会话、读工具过程、写消息。不是营销落地页。

## 本轮约束
- 只做视觉与层次，不改功能与协议
- 保留现有信息结构：侧栏、顶栏、对话流、输入条、任务清单、工具折叠
- 假数据用真实中文对话片段，三版同内容
- 输出：1280×800 桌面窗 mock（单文件 HTML）
- 禁区：紫渐变、玻璃拟态堆、到处圆角胶囊、装饰图标墙

## 气质关键词
专业、安静、可读、工具感、中文友好

## 三套逻辑
1. 秒数轮盘 → 网页风格 #10 Bauhaus Geometric（几何色块模块化）
2. 现实参照 → Cursor / Claude 桌面对话壳的密度与暗色克制
3. 最佳设计师思维 → Linear 式精密排版（细线、字重、间距）
