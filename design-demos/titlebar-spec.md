# 顶栏 / 图标 · 设计 Spec

## 问题
当前窗口只有系统默认标题条，里面几乎没有品牌感；页面顶栏又重复写「Hi-agent」，整体显得空、丑。

## 目标
- 最上方增加类似系统应用的菜单栏气质：图标 + File / Edit / View / Help + 窗控
- 补上应用图标（可作窗口图标与侧栏品牌）
- 与已选方向 C「精密纸面」一致：浅暖灰、细线、不堆装饰
- 本轮只出视觉；菜单项具体命令可后挂（先占位）

## 菜单草案（实现时可接斜杠命令）
| 菜单 | 项 |
|------|----|
| File | New Session、Open Project…、Save、Exit |
| Edit | Undo File Write、Copy、Paste |
| View | Toggle Theme、Permissions、Todos |
| Help | Help、About |

## 三版差异
1. **系统双层**：仿截图的菜单条 + 下方保留现有产品顶栏
2. **合并单层**：菜单与产品状态同一条，更省高度
3. **品牌优先**：左侧大图标+产品名，菜单缩成文字链，窗控靠右
